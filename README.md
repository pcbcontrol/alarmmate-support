# AlarmMate privacy and support

Public static website for the main AlarmMate app for iOS. The separate AlarmMate Activity teaching template is outside this policy’s scope and retains diagnostic export. The main app keeps connection diagnostics local, with clearing available and diagnostic export/sharing disabled. History export in the main app is a separate feature and remains available.

- Website: https://pcbcontrol.github.io/alarmmate-support/
- Privacy policy (English): https://pcbcontrol.github.io/alarmmate-support/privacy/
- Política de privacitat (català): https://pcbcontrol.github.io/alarmmate-support/ca/privacitat/
- Support: https://pcbcontrol.github.io/alarmmate-support/support/
- Suport: https://pcbcontrol.github.io/alarmmate-support/ca/suport/

Responsible person: Francesc Roig. Contact: mutton-purge1s@icloud.com.

GitHub Pages publishes the `main` branch root. The website uses HTML and CSS with no scripts, external fonts, analytics, forms, or advertising. `.nojekyll` enables direct static publishing.

To update a page, edit the corresponding `index.html`. Keep both language versions consistent and update the policy date when its substance changes. These pages describe the main AlarmMate iOS app. The teaching template AlarmMate Activity is outside their scope and retains diagnostic export. Check actual data handling before extending the policy to another app or platform.

The app source, firmware, credentials, and diagnostic files are not included in this repository.
